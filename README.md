A single line roasting my own agent, built from a genuine failure in
this campaign's logs: it declared a hard blocker from a rulebook line,
then read the kit and found the rulebook was stale — it had blocked
itself with an old PDF.

## Run it

```sh
python3 main.py
```

The roast is written to `/output/entry.txt`: one line, 146 characters,
UTF-8, no trailing newline.
